## 模块 B：Redis 计费（feat/billing 分支）

### 实现
- `src/services/billingService.js`：
  - `deduct(tenantId, points)` — 使用 Lua 脚本：`EVAL "local bal=tonumber(redis.call('GET',KEYS[1])or 0);if bal<tonumber(ARGV[1])then return -1 end;return redis.call('DECRBY',KEYS[1],ARGV[1])" 1 billing:${tenantId} ${points}`
    - 返回 -1 表示余额不足 → `{ ok: false, reason: 'INSUFFICIENT' }`
    - 否则 → `{ ok: true, balance: result }`
  - `getBalance(tenantId)` — `redis.get(`billing:${tenantId}`)`，转数字
  - `seed(tenants)` — 遍历 `Object.entries(tenants)`，对每个执行 `redis.set(`billing:${tenantId}`, balance, 'NX')`

- `src/routes/v1/billing.route.js` — `/balance` 路由：
  - 调用 `billingService.getBalance(req.tenantId)`
  - 返回 `{ tenantId: req.tenantId, balance }`

### 验证
```bash
# 启动后检查 seed 是否成功
redis-cli GET billing:tenant-001
# 应返回 "100"
```

## 模块 C：BullMQ 队列（feat/jobs 分支）

### 数据模型
- `src/models/job.model.js` — 补全 Schema：
  ```js
  {
    jobId: { type: String, required: true, unique: true },
    tenantId: { type: String, required: true },
    status: { type: String, enum: ['queued', 'processing', 'completed', 'failed'], default: 'queued' },
    phases: [{ name: String, status: String, completedAt: Date }],
    createdAt: { type: Date, default: Date.now },
    completedAt: Date
  }
  ```

### 服务层
- `src/services/jobService.js`：
  - `submit(tenantId, payload)`：
    1. `const deduction = await billingService.deduct(tenantId)`，若 `!deduction.ok` 抛出 `ApiError(402, 'Insufficient balance')`
    2. `const jobId = uuidv4()`
    3. `await getQueue().add(jobId, { jobId, tenantId, phases: PHASES })`
    4. `await Job.create({ jobId, tenantId, status: 'queued', phases: [] })`
    5. 返回 `{ jobId }`
  - `getJob(jobId, tenantId)` — `Job.findOne({ jobId, tenantId })`

- `src/routes/v1/jobs.route.js`：
  - `POST /` — 调用 `jobService.submit(req.tenantId, req.body.payload)`，返回 201 `{ jobId }`
  - `GET /:id` — 调用 `jobService.getJob(req.params.id, req.tenantId)`，返回 Job 文档

### Worker
- `workers/jobWorker.js` — 实现 `processJob`：
  1. `const { jobId, tenantId } = job.data`
  2. `await Job.findOneAndUpdate({ jobId }, { status: 'processing' })`
  3. 遍历 `PHASES`，每阶段：
     - `await new Promise(r => setTimeout(r, PHASE_DELAY_MS))`
     - `await Job.findOneAndUpdate({ jobId }, { $push: { phases: { name, status: 'completed', completedAt: new Date() } } })`
     - `eventBus.emit(`job:${jobId}`, { jobId, phase: name, status: 'completed', progress: Math.round(((i+1)/PHASES.length)*100), log: `Phase ${name} completed` })`
  4. 全部完成：`await Job.findOneAndUpdate({ jobId }, { status: 'completed', completedAt: new Date() })`
  5. 错误处理：try/catch 中 `await Job.findOneAndUpdate({ jobId }, { status: 'failed' })` 并 emit 失败事件

### 验证
```bash
curl -X POST http://localhost:3000/v1/jobs \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"payload":{}}'
```

## 模块 D：WebSocket 实时进度（feat/ws-progress 分支）

### 服务端
- `src/lib/wsServer.js` — 实现 `attachWsServer`：
  1. `const wss = new WebSocket.Server({ server, path: '/ws/job' })`
  2. `wss.on('connection', (ws, req) => { ... })`
  3. 解析 `req.url`：提取 `jobId` 和 `token` query 参数
  4. `jwt.verify(token, config.jwt.secret)` 验证 token
  5. 查 MongoDB `Job.findOne({ jobId, tenantId: payload.tenantId })`，不存在则 `ws.close(4001, 'Unauthorized')`
  6. 验证成功：
     - `const listener = (event) => ws.send(JSON.stringify(event))`
     - `eventBus.on(`job:${jobId}`, listener)`
     - 收到 `progress === 100` 后 `setTimeout(() => ws.close(), 500)`
     - `ws.on('close', () => eventBus.off(`job:${jobId}`, listener))`

### 前端
- `frontend/pages/dashboard.jsx`：
  - `useEffect` 初始化：从 `localStorage` 读取 token，不存在则 `router.push('/login')`
  - `fetchBalance`：`fetch(`${process.env.NEXT_PUBLIC_BACKEND_URL}/v1/billing/balance`, { headers: { Authorization: `Bearer ${token}` } })`
  - `submitJob`：POST `/v1/jobs`，成功后调用 `connectWs(data.jobId)`
  - `connectWs(jid)`：
    - `new WebSocket(`${process.env.NEXT_PUBLIC_WS_URL}/ws/job/${jid}?token=${token}`)`
    - `ws.onmessage`：解析 JSON，更新 progress/currentPhase/logs
    - `progress === 100` 时 `setDone(true)` 并 `fetchBalance()`
    - 处理 `ws.onerror` / `ws.onclose`

### 验证
打开浏览器 `http://localhost:3001/login` 登录后，在 Dashboard 提交任务，观察实时进度条。

## 模块 E：Docker + Git（chore/compose 分支）

### 创建 `frontend/Dockerfile`
```dockerfile
FROM node:20-alpine
WORKDIR /app
COPY package.json pnpm-lock.yaml ./
RUN npm install -g pnpm && pnpm install
COPY . .
RUN pnpm build
EXPOSE 3001
CMD ["pnpm", "start"]
```

### 补全 `docker-compose.yml`
- **mongodb**：添加 `healthcheck: { test: ["CMD", "mongosh", "--eval", "db.adminCommand('ping')"], interval: 10s, timeout: 5s, retries: 5 }`，添加 `volumes: - mongodb_data:/data/db`
- **redis**：添加 `healthcheck: { test: ["CMD", "redis-cli", "ping"], interval: 10s, timeout: 5s, retries: 5 }`，添加 `volumes: - redis_data:/data`
- **backend**：添加 `depends_on: mongodb: condition: service_healthy, redis: condition: service_healthy`
- **frontend**：添加 `depends_on: [backend]`，添加 `environment: NEXT_PUBLIC_BACKEND_URL=http://localhost:3000, NEXT_PUBLIC_WS_URL=ws://localhost:3000`
- 底部定义 `volumes: mongodb_data:, redis_data:`

### Git
- 每个模块一个 feature 分支，语义化 commit
- 最后合并到 main
